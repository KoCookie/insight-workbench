# Roadmap

## Phase 0: Product Definition

Goal: define the product clearly enough to build a focused MVP.

Deliverables:

- Product brief
- PRD draft
- MVP scope
- Initial information architecture
- Private benchmark validation plan

## Phase 1: Prototype

Goal: create a clickable or lightweight working prototype that demonstrates the core workflow.

Target capabilities:

- Create a research topic
- Choose a research goal
- Generate a research blueprint
- Add mock sources
- Display an initial dashboard
- Show insight cards and evidence links
- Generate a basic research brief

Suggested validation:

- Use a private benchmark research project as a validation topic
- Compare generated dashboard modules with existing human deliverables
- Record missing information, weak reasoning, and unsupported claims

## Phase 2: MVP

Goal: build a deployable single-user web app.

Target capabilities:

- Topic-based workspace
- Source upload and link management
- AI-assisted source extraction
- Editable dashboard widgets
- Basic analysis lab tools
- Exportable research brief
- Source-grounded insight cards

Not required:

- Full collaboration
- Automatic web monitoring
- Enterprise permissions
- Complex version control

## Phase 3: Update Workflow

Goal: make the project structure feel lightweight by supporting ongoing topic tracking.

Target capabilities:

- Source checklist per topic
- Manual update reminders
- "What changed since last update" view
- Evidence gap reminders
- Outdated conclusion warnings

## Phase 4: Advanced Analysis

Goal: add deeper analysis functions for interns, analysts, and consultants.

Target capabilities:

- Technology-scenario matrix
- Maturity assessment builder
- Weighted priority scoring
- Three Horizons roadmap
- Evidence quality scoring
- Reusable project templates

## Phase 5: Professional Workspace

Goal: support more professional consulting research workflows.

Target capabilities:

- Project templates
- Insight library
- Versioned outputs
- Team collaboration
- Advanced source governance
- Report and slide export
